
# Nova Retail Group
## Data Analytics & Machine Learning Project


## معرفی پروژه

Nova Retail Group یک شرکت خرده‌فروشی در حوزه محصولات آرایشی،
عطر و مراقبت پوست است.

هدف این پروژه تحلیل داده‌های فروش، مشتریان، محصولات،
موجودی و کمپین‌های بازاریابی با استفاده از تکنیک‌های
Data Analytics و Machine Learning است.


## اهداف پروژه

- تحلیل عملکرد فروش
- شناسایی مشتریان ارزشمند
- بخش‌بندی مشتریان
- پیش‌بینی ریزش مشتریان
- پیش‌بینی فروش آینده
- بهبود مدیریت موجودی
